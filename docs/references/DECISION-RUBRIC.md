# Research Direction Decision Rubric

Compare candidates by the value of the next research step. Give a short rationale for each relevant dimension rather than an opaque aggregate score.

## Readiness to explore

A candidate can enter exploration when it has:
- a worthwhile problem;
- a concrete proposal with reasonable intuition;
- an observable expected outcome and a feasible first test.

Before recommending substantial investment, compare the closest prior work and address concrete issues that could remove the contribution's value or make the test uninterpretable. A targeted exploratory experiment may be useful while a literature question remains open; state which question and how it affects the decision.

## Comparison dimensions

1. **Problem value:** What capability, efficiency, practice, or understanding would improve?
2. **Difference from prior work:** What does the proposal add, and why does the difference matter?
3. **Rationale:** Is there a reasonable reason to try it? Assess theory or mechanism depth when that is the intended contribution.
4. **Test value:** Would the first experiment or analysis inform the decision to continue or revise?
5. **Tractability:** Can the first test be performed with available data, methods, and resources?
6. **Decision-relevant risk:** Which concrete issue, if any, changes the priority or test design?

A method's simplicity does not determine its contribution. Evaluate combinations, training strategies, losses, and prompts using the same dimensions as other proposals.

## Recommendation labels

- `pursue`: the potential value and feasible next test justify exploration.
- `refine`: the problem, proposal, comparison, or test needs sharpening.
- `defer`: a specific prerequisite or resource constraint blocks useful progress.
- `reject`: prior work already supplies the intended contribution, evidence undermines its rationale, or the proposed result would not be useful.

Include the reason for the recommendation, the smallest useful next action, and how its results would change the decision. Include objections when they change that action or recommendation.
