# Research Glossary

Use these terms consistently across the project. Keep this file about domain language, not implementation details.

| Term | Definition |
|---|---|
| **Research question** | A bounded question whose answer would change understanding of a phenomenon, method, or field. |
| **Research opportunity** | An evidence-grounded reason to investigate a question. A gap in a paper list alone is insufficient. |
| **Hypothesis** | A testable proposition that predicts an outcome under stated assumptions and conditions. |
| **Mechanism** | The proposed process or causal structure explaining why a hypothesis should hold. |
| **Prediction** | An observable consequence that should occur if a hypothesis is correct. |
| **Falsification condition** | An observation that would materially weaken or reject a hypothesis. |
| **Prior work** | Existing research relevant to the question, method, mechanism, or claimed contribution. |
| **Closest prior work** | The existing work that most directly overlaps with the proposed contribution, regardless of venue or prestige. |
| **Contribution claim** | A precise statement of what new knowledge, capability, explanation, or evidence the work would add. |
| **Evidence** | A source-grounded observation or result that supports, contradicts, qualifies, or contextualizes a claim. |
| **Evidence locator** | A stable pointer to the exact source location, such as a section, page, figure, table, theorem, or dataset record. |
| **Novelty** | A substantive difference from prior work. Novelty may concern the problem, mechanism, method, theory, finding, evaluation, or demonstrated boundary. |
| **Research direction** | A selected hypothesis or connected set of hypotheses that the researcher has decided to investigate. |
| **Decisive test** | The smallest informative test that guides a research decision; it may compare methods or distinguish explanations. |
| **Belief update** | A recorded change in confidence or status caused by new evidence. |
| **Research decision** | A traceable choice to continue, revise, defer, or reject a question or hypothesis, with rationale. |
| **Corpus boundary** | The explicit limits of the literature set searched or reviewed. |
| **Unknown** | Something not established by the available evidence. Unknowns must remain visible rather than being filled with plausible-sounding assumptions. |
